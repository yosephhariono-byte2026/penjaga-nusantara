# Bata Biru

Game puzzle balok jatuh bergaya 8 bit dengan tema porselen Gzhel Rusia (biru kobalt di atas putih),
matryoshka, dan kubah bawang. Satu file HTML, tanpa library, bisa dimainkan di HP dan laptop.

Main langsung: https://claude.ai/artifact/Wpv769EZP75LgSX6tauaoR
Atau buka `index.html` di browser.

## Kontrol

| Aksi | Keyboard | HP |
|---|---|---|
| Mulai | Enter | ketuk layar |
| Geser | panah kiri / kanan | tombol ◀ ▶ |
| Putar | panah atas (Z putar balik) | PUTAR |
| Turun cepat | panah bawah | ▼ |
| Jatuh langsung | Spasi | JATUH |
| Jeda | P | JEDA |
| Musik / efek suara | N / M | MUSIK / SUARA |

## Aturan

- Papan 10 x 20, tujuh bentuk balok, dengan pratinjau balok berikutnya dan bayangan tempat mendarat.
- Awal permainan pelan (cocok untuk pemula). Kecepatan naik sedikit setiap garis yang hilang,
  sekitar 10% lebih cepat tiap 10 garis.
- Skor: 1 garis 100, 2 garis 300, 3 garis 500, 4 garis 800, dikali level.
- Skor tertinggi tersimpan di browser masing-masing.
- Musik: melodi tari rakyat bergaya Rusia buatan sendiri; temponya ikut naik bersama kecepatan.

## Game lain di repo ini

Masing-masing satu file HTML tanpa instalasi. Buka `index.html` di foldernya.

### Penjaga Nusantara (`penjaga-nusantara/`)

Tembak-menembak bergaya wayang kulit. Terbangkan Garuda, panah bala Buto, Leak, dan Kalong,
lalu jaga tujuh pulau dari Sumatra sampai Papua. Ada dua gaya tampilan: wayang kulit, atau retro
piksel dengan suara chiptune.

Main langsung: https://claude.ai/artifact/FkVW9Y4qKfgjV1RJkQSxUd

- Gerak: panah kiri/kanan atau A/D. Memanah: Spasi. Jeda: P. Suara: M. Ganti gaya: G
- Layar sentuh: geser jari di layar, atau pakai tombol di bawah
- Pusaka: Keris (panah menembus), Gong (musuh terpaku), Payung (menahan satu serangan), Kendi (tambah nyawa)

### Candi Runtuh (`candi-runtuh/`)

Pemecah batu bergaya retro. Bongkar tumpukan batu dengan bola, lalu tangkap batu yang jatuh
untuk menyusun kembali relief candi. Lima candi: Borobudur, Mendut, Prambanan, Penataran, dan Sukuh.

Main langsung: https://claude.ai/artifact/FfmCu9djMGHDGuwCz7vDq4

- Gerak tandu: tetikus, jari, atau panah kiri/kanan. Lepas bola: klik, ketuk, atau Spasi. Jeda: P. Suara: M
- Tiga nyawa. Bola yang lolos mengurangi nyawa, batu yang lolos hanya pecah.
- Batu emas menjatuhkan bantuan: L (tandu lebar), P (bola pelan), N (nyawa)
